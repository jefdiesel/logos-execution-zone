EXAMPLE RUN of testnet/ (LEZ v0.4.0-rc3 + the WAL/fd patch), 2026-11-13, macOS 15 on an Apple M4.
A clean clone of this branch, then what a newcomer types. Only paths were shortened: the kit home
is shown as ~/lez-test and the binaries as ~/prebuilt/. Account ids and public keys are from a
throwaway chain. Nothing secret is printed by the kit (the recovery phrase goes to a mode-600 file).

Binaries: sequencer_service (--features standalone,prove) and wallet (--features lee/prove) were
built from this same source tree with the same cargo commands sequencer/build.sh runs, then passed
in with SEQ_BIN/WALLET_BIN, because the build host's shared build queue was busy. The from-source
path (build.sh inside up.sh) is run by the testnet-kit GitHub workflow on every push.
Part 1 ran with the scripts as of the first push; parts 2 and 3 with the current ones (smoke.sh
gained the segment-count retry and the opt-in --call between them).
